The SQL in the `exercise.sql` file
- Should alter the row in the `Employee` table for the employee with the `ID` 1017, with the following new information:
   - Employee's `NAME` should be 'Thomas'
   - Employee's `SALARY` should be '1212'
   - Employee's `LOCATION` should be 'New York'
   - Employee's `DATE_OF_BIRTH` should be '1975-11-08'
   - Employee's `EDUCTAION` should be 'Masters'
